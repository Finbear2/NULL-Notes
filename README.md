# Null-Notes
###### If obisidian was easy and looked like notion... somewhat
---
### What is it
---
Null Notes is a **very** work in progress markdown notes app links notes like obsidian but with typed words and not specified links.

It uses Python, then flask to connect with the html, and good old CCS for styling with a little bit of javascript so the frontend isn't constantly making requests to the backend. For the markdown editor it uses easy mde.

### WARNING
---
This is the defenition of spaggetti code. This should be an example of how not to code in classrooms. It is also definitely not finished with it allowing you to edit notes but not create notes.

**This repo is mostly to showcase where it is at to friends**
